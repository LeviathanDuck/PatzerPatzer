# Security policy

Do not open a public issue for a suspected vulnerability, credential exposure, authentication
problem, private user data, or hosting and deployment weakness.

Use GitHub's **Report a vulnerability** / private vulnerability reporting flow from this
repository's Security tab when that option is available. If the private reporting option is not
available, do not publish the details in Issues. Contact the repository owner through their GitHub
profile and ask for a private reporting channel without including vulnerability details.

Public bug forms are only for non-security product behavior and must not contain credentials,
authorization values, private identifiers, raw logs or payloads, game records, attachments, local
paths, or infrastructure details.
