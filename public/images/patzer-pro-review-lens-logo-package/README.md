# Patzer Pro — Review Lens Logo Package

Direction: app logo based on option #2, the review lens. The mark is intentionally simple: a magnifying lens for analysis/review, a green check for finding the right move, and no chess-board background.

## Included

- `svg/patzerpro-app-icon.svg` — primary app icon
- `svg/patzerpro-mark-dark-ui.svg` — transparent mark for dark UI
- `svg/patzerpro-mark-light-ui.svg` — transparent mark for light UI
- `svg/patzerpro-lockup-horizontal-dark-ui.svg` — horizontal website header/logo
- `svg/patzerpro-lockup-horizontal-light-ui.svg` — light-background lockup
- `svg/patzerpro-lockup-stacked-dark-ui.svg` — stacked lockup
- `web/favicon.ico`
- `web/favicon.svg`
- `web/favicon-16x16.png`
- `web/favicon-32x32.png`
- `web/apple-touch-icon.png`
- `web/android-chrome-192x192.png`
- `web/android-chrome-512x512.png`
- `web/site.webmanifest`

## Usage

Use the app icon for favicon/PWA/mobile. Use the horizontal dark UI lockup in the main site nav. Use the transparent mark only when the background is already controlled.
